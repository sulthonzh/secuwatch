# webperf - Zero-Config Web Performance Monitoring CLI

**Demand Score: 7/10**  
**Spec Score: 28/35**

## Problem Statement

Web developers need to quickly monitor their application performance but existing solutions are problematic:

- **perfume.js** (10.7k⭐) requires library integration into web application code
- **Google Chrome DevTools** requires manual testing and GUI interaction  
- **Lighthouse** requires complex setup and configuration
- **Chrome web-vitals-extension** is a browser extension, not CLI
- **puppeteer-webperf** requires Puppeteer setup and automation scripting

Developers want a simple CLI tool to run quick performance checks without:
- Modifying their web application code
- Setting up complex infrastructure  
- Learning new APIs or configuration
- Using GUI tools

**Evidence of Demand:**
- Chrome DevTools MCP has 41k⭐ showing strong browser development tool demand
- perfume.js has 10.7k⭐ validating web performance monitoring need
- Multiple issues in GitHub discussions asking for CLI alternatives to performance testing

## Proposed Solution

`webperf` - A zero-config CLI tool that analyzes web application performance using Web Vitals and other key metrics. Reports results in a clean, human-readable format.

**Usage Examples:**
```bash
# Quick performance check
webperf https://example.com

# Check multiple URLs  
webperf https://app.com https://api.app.com

# Save results to file
webperf https://example.com --output report.txt

# Monitor specific page
webperf --page home https://example.com

# Continuous monitoring (watch mode)
webperf --watch https://example.com
```

## Architecture & API Design

### Core Architecture
- **TypeScript** + Node.js for cross-platform compatibility
- **Chrome DevTools Protocol** via `puppeteer` for automated testing
- **Web Vitals** library integration for standardized metrics
- **Zero-config** approach with sensible defaults

### Key Metrics Collected
- **Core Web Vitals**: LCP, FID, CLS, INP
- **Performance Metrics**: TTFB, FCP, TBT, NTBT
- **Network Metrics**: DNS lookup, TCP connection, request/response times
- **Resource Metrics**: Total transfer size, number of requests
- **Device Information**: Connection type, device type classification

### CLI Interface
```bash
webperf [URL] [options]

Options:
  --output FILE     Save results to file
  --watch           Continuous monitoring mode
  --page NAME       Test specific page/route  
  --device MOBILE|DESKTOP|TABLET  Device type
  --connection SLOW|4G|WIFI  Network condition
  --thresholds FILE  Custom performance thresholds
  --json            JSON output format
  --verbose         Detailed output
```

## Configuration

Create `.webperf.json` for custom settings:
```json
{
  "thresholds": {
    "LCP": 2500,
    "FID": 100,
    "CLS": 0.1,
    "INP": 200
  },
  "defaultDevice": "mobile",
  "network": "4g"
}
```

## API

```typescript
import { webperf } from 'webperf';

// Programmatic usage
