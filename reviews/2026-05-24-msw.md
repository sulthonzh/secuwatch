## Review Findings

### 🔒 Security
- **Prototype Pollution in GraphQL multipart handling** (`parseGraphQLRequest.ts:72-95`): The `extractMultipartVariables` function uses user-controlled `map` paths to traverse objects without sanitizing `constructor`/`prototype` keys. A crafted multipart GraphQL request can achieve `Object.prototype` pollution. Severity reduced because MSW is a dev/test tool, but still a real vulnerability especially in CI environments.

### 🐛 Bugs
- **Unhandled QuotaExceededError in CookieStore** (`cookieStore.ts:82-95`): `localStorage.setItem` is called without try/catch. When storage is full, the exception propagates up and crashes the entire request handling pipeline. Affects long-running test suites.
