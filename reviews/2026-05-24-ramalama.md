## Review Findings

### 🔒 Security
- `install.sh` uses `curl | bash` for `install-uv.sh` without integrity verification (checksum/signature). Nested invocation compounds supply chain risk.
- `http_client.py` uses `urllib.request.urlopen` with system certs — no certificate pinning, acceptable for this use case.
- `run_cmd()` in `common.py` uses `subprocess.run()` with argument lists (not shell=True) — good, no command injection risk.
- Proxy support module properly handles SOCKS with graceful fallback when PySocks is missing.

### 🐛 Bugs
- **ZeroDivisionError in `calculate_speed()`**: When download completes in <1ms, `elapsed_seconds` is 0, causing crash. Affects fast downloads of small files.
- **Orphaned `.partial` files**: Failed downloads leave partial files without cleanup. No integrity check on resumed partial content — could result in corrupted final files.

### ⚡ Performance
- Progress bar updates throttled to 0.1s intervals — good.
- Exponential backoff with cap on retries — well implemented.
- `@lru_cache` used for config lookups in CLI — good.

### 📐 Architecture
- Clean separation of transports (OCI, HuggingFace, ModelScope, URL, Ollama) via transport factory pattern.
- Plugin system for runtimes (llama.cpp, MLX, vLLM) is extensible.
- File locking via `fcntl` with platform detection — solid approach.
- Model store abstraction handles snapshots, blobs, and caching well.
